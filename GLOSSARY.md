# Glossary

| Term | Meaning |
| --- | --- |
| AWS account | The AWS ownership and access boundary identified by a twelve-digit account ID. |
| Project | This deployment learning exercise, which can contain multiple environments. |
| Environment | An independently selected deployment target with its own credentials, resources and data. |
| Administrator allowlist | The approved public IPv4 addresses allowed to access the learning environment's cluster API and application. |
